## Download on a phone

Chat download cards often fail on Android. Use GitHub instead:

1. Open this repo: https://github.com/Gavjosie/peptide-library
2. Tap the green **Code** button
3. Tap **Download ZIP**
4. Save to Files / Drive

Or open the single-file dump:
- https://github.com/Gavjosie/peptide-library/raw/main/SOURCE.txt
